A website which allows users to have all bookmarks from different browsers in one place.

# Convergence
Convergence is a web application that consolidates bookmarks from various browsers,services- like Youtube,Reddit,X,and Github into a single, easy-to-access location. It aims to simplify bookmark management by providing a unified interface for users to view, organize, and access their bookmarks regardless of the browser they were originally saved in.

Also working on a extension based feature where users can directly search for these bookmarks - akin to Spotlight Search on MacOS.
